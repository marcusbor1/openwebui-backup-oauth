Privacy Policy

Application: rclone Open WebUI Backup

Last updated: November 9, 2026

1. Purpose

This is a personal, non-commercial integration used by its owner to back up a self-hosted Open WebUI installation to Google Drive using rclone. It is not offered as a public service.

2. Google Drive access

The integration uses Google OAuth 2.0 and requests the Google Drive drive.file permission. This allows rclone to create, access, update and delete files associated with the application.

Google Drive access is used for uploading, listing, managing, retrieving and verifying personal backup files. The integration does not request access to Gmail, contacts or unrelated Google services.

3. Data processed

Backup archives may contain Open WebUI settings, conversations, uploaded files and other application data. Backup operations may also process file names, metadata and authentication information needed to access Google Drive.

Google API data is used only to perform the backup and recovery operations described in this policy.

4. Storage and security

Backup archives are encrypted locally using rclone crypt before being transferred to Google Drive. Google Drive stores the encrypted backup archives.

OAuth credentials and encryption configuration are maintained separately on the owner's private server. They are not published on this website.

The owner controls access to the server and Google account. No storage or transmission method is completely risk-free.

5. Sharing and use of data

Google Drive is used as the storage provider for encrypted backup files. The integration does not sell Google user data, use it for advertising or profiling, or disclose it to data brokers.

Google user data is not transferred to third parties for purposes unrelated to personal backup and recovery.

6. Retention and deletion

Backup files are retained according to the owner's backup retention settings. The owner may delete backup files from Google Drive and local storage.

Google account access can be revoked through Google Account settings. Revoking access does not automatically delete previously stored backup files.

7. Google API Services User Data Policy

Google user data is accessed and used only for the personal backup and recovery functions described in this policy. It is not used for advertising, profiling, or unrelated purposes.

The integration's use of Google API data is intended to comply with the Google API Services User Data Policy, including applicable Limited Use requirements.

8. Changes to this policy

This policy may be updated if the integration's functionality or data-handling practices change. The current version will be available on this page.

9. Project information

Information about this personal integration is available in the GitHub project repository .
