rclone Open WebUI Backup

About this application

rclone Open WebUI Backup is a personal, non-commercial integration used to back up data from a self-hosted Open WebUI installation to Google Drive.

This integration is used only by its owner. It is not offered as a public service.

Google Drive access

The integration uses Google OAuth 2.0 and the Google Drive drive.file permission to store and manage backup files associated with the application.

Backup archives are encrypted locally using rclone before being uploaded to Google Drive. Google Drive is used as the backup storage destination.

Privacy and data handling

For information about how Google Drive data is accessed, used, stored and protected, please read the Privacy Policy.
